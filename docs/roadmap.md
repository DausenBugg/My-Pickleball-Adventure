# Roadmap

## v1.0 — MVP ✅ (Complete)
- [x] Auth: registration, login, email verification, password reset.
- [x] Home KPIs: wins, losses, level, recent matches, XP to next level, ranking.
- [x] Add match: singles/doubles, ranked/casual, score validation, opponent search.
- [x] Recent players in search.
- [x] Match approval workflow (excludes self-submitted).
- [x] Global and friends leaderboards.
- [x] Settings: update profile, notifications, account details.
- [x] Achievements with progress tracking.
- [x] Push notifications (match approvals, friend requests, achievements).
- [x] Match history with filtering (all/wins/losses).
- [x] AdMob banner ads.
- [x] Wear OS watch app (login, match logging, approvals, settings).
- [x] CI/CD: GitHub Actions + EAS Build/Submit.
- [x] OTA updates via expo-updates.
- [x] Privacy policy.

## Next

- Public profile sharing and privacy controls.
- Photo attachments on matches.
- Apple Watch companion app.
- Automated tests (unit + integration).
