# Roadmap

## MVP
- Auth: registration, login, password reset.
- Home KPIs: wins, losses, level, recent matches, XP to next level, ranking.
- Add match: singles/doubles, score validation, opponent search.
- Match approval workflow.
- Global and friends leaderboards.
- Settings: update profile and account details.
- Achievements and notifications.

## Next
- Match dispute flow.
- Clubs/venues with local leaderboards.
- Seasonal ranked ladders.
- Public profile sharing and privacy controls.
